# Ahmed Early Signal Scanner

ماسح مستقل عن تنبيهات TradingView. يتصل مباشرة بعقود Binance Futures الدائمة المقومة بـ USDT، ويحسب منطق العلامة المبكرة من مؤشر **Ahmed Pro Ultimate v11** على الفريمات:

- 15m
- 1h
- 4h
- 1d
- 1w

يرسل تنبيه تيليجرام عند ظهور علامة شراء/بيع مبكرة أثناء تكوّن الشمعة، ويرسل تنبيهًا آخر إذا انطفأت العلامة قبل أن تتحول إلى شمعة ذهبية.

## مهم جدًا قبل التشغيل

لا تضع توكن البوت داخل GitHub. استخدم Railway Variables فقط. بما أن التوكن السابق كُتب داخل محادثة، غيّره من BotFather عبر `/revoke` أو إنشاء توكن جديد، ثم استخدم التوكن الجديد.

## رفع المشروع إلى GitHub

1. أنشئ Repository جديدًا، مثل: `Ahmed-Early-Signal-Scanner`.
2. ارفع جميع ملفات هذا المجلد كما هي.
3. تأكد أن المستودع لا يحتوي على ملف `.env` ولا يحتوي على التوكن.

## تشغيله على Railway

1. افتح Railway واختر **New Project**.
2. اختر **Deploy from GitHub repo**.
3. اختر المستودع الجديد.
4. افتح **Variables** وأضف:

```text
TELEGRAM_BOT_TOKEN=التوكن_الجديد
TELEGRAM_CHAT_ID=-1004394911035
TIMEFRAMES=15m,1h,4h,1d,1w
EARLY_SCORE=58
GOLDEN_SCORE=78
EARLY_MTF_COUNT=1
REQUIRE_GOLD_MTF_COUNT=3
REQUIRE_GOLD_BREAKOUT=true
SEND_STARTUP_MESSAGE=true
MAX_SYMBOLS=0
```

5. اضغط Deploy. لا تحتاج إلى Domain لأن الخدمة Worker وليست موقع ويب.
6. راقب Logs حتى يظهر:
   - عدد العملات التي تتم مراقبتها.
   - اكتمال تحميل التاريخ.
   - اتصال WebSocket shards.

## تجربة آمنة أولًا

ضع `MAX_SYMBOLS=10` للتأكد من وصول رسالة التشغيل وعدم وجود أخطاء. بعد نجاح الاختبار اجعله `MAX_SYMBOLS=0` ليعمل على جميع عقود USDT الدائمة.

## مطابقة المؤشر

المشروع يطابق الإعدادات الافتراضية ذات الصلة بالعلامة المبكرة:

- درجة العلامة المبكرة: 58.
- الدرجة الذهبية: 78.
- عدد الفريمات المتوافقة للعلامة المبكرة: 1.
- فريمات التوافق الثابتة: الحالي + 1H + 4H + D.
- لا يعتبر انتقال العلامة المبكرة إلى ذهبية إلغاءً.
- يرسل الإلغاء فقط عندما كانت العلامة نشطة ثم فقدت شرطها داخل الشمعة نفسها.

## تنبيه تقني

النتائج تهدف لمطابقة معادلات Pine، لكن قد توجد فروقات صغيرة في أول تشغيل بسبب طريقة تهيئة EMA وتوقيت تحديث بيانات Binance مقارنة بتغذية TradingView. بعد اكتمال السجل واستمرار الخدمة تصبح الحسابات مستقرة.
